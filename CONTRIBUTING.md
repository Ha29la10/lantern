# Contributing to Lantern

## Development Conventions

- Use Python 3 and the standard library.
- Keep changes focused and easy to review.
- Follow Conventional Commits.

## Commit Messages

Use:

type(scope): description

Examples:
- feat(cli): add task sorting
- fix(storage): handle missing files
- docs(readme): update usage guide

## Branch Workflow

- Create a short-lived branch for each change.
- Push your branch to GitHub.
- Open a pull request against main.
- Request a review from the other contributor.
- Merge only after approval.

## Code Quality

- Test your changes before opening a pull request.
- Do not commit generated files, secrets, or local environment files.
