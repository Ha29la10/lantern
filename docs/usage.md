# Lantern Usage Guide

## Overview
Lantern is a command-line task management application.

## Installation
Clone the repository:

```bash
git clone git@github.com:omarabushanab/lantern.git
cd lantern
```

## Running the Application
Run the application using Python:

```bash
python lantern.py
```

## Available Commands
The application provides commands for managing tasks.

- `add`: Add a new task.
- `list`: Display the tasks.
- `done`: Mark a task as completed.
- `remove`: Remove a task.

## Data Storage
Tasks are stored locally in a JSON file.
