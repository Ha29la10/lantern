# Lantern

Lantern is a tiny command-line task tracker written in Python 3 (standard library only).

## Installation & Usage

### Prerequisites
* Python 3.x ( standard library only — no external dependencies required )

### Running Lantern

```bash
# Display help and available options
python lantern.py --help

# Add a new task
python lantern.py add "Buy groceries"

# List tasks
python lantern.py list
```

For detailed usage documentation and advanced command options, check out the [Usage Guide](docs/usage.md).

## Commands

- `lantern add` — Add a new task to your task list.
- `lantern list` — View all recorded tasks.
